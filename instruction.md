# Copilot Instructions

Please read this file before generating or modifying code in this project.

## How to use these instructions
- Follow the instructions in this file first.
- Use them as the main guide for coding style, structure, and behavior.
- If the request is unclear, ask a clarifying question before making changes.

## Coding guidelines
- Write clean, readable, and maintainable Python code.
- Follow the existing project style and naming conventions.
- Use simple and descriptive variable names.
- Keep functions focused and modular.
- Add comments only where they improve clarity.
- Prefer Python standard library features before adding new dependencies.

## Project-specific expectations
- Respect the existing folder structure and file responsibilities.
- Reuse existing modules where appropriate instead of duplicating logic.
- Keep the code compatible with the current Python environment.
- Handle errors gracefully and provide useful messages.
- Preserve the behavior of the app unless the user explicitly requests a change.

## Code generation rules
- When generating code, first understand the task and the project context.
- Prefer small, tested, and well-structured changes.
- Avoid unnecessary complexity.
- Make sure the generated code is syntactically correct and runnable.
- If a feature requires external packages, mention the dependency clearly.

## Response style
- Provide concise explanations.
- Mention important changes clearly.
- If something cannot be completed, explain why and suggest the next step.
